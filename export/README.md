# Import στο Google My Maps

Αρχεία έτοιμα για εισαγωγή, ώστε να φτιάξεις **δικό σου χάρτη My Maps** και να τον
μοιραστείς με κανονικό link Google Maps — χωρίς να χρειάζεται κανείς να μάθει την εφαρμογή.

## Τι να κατεβάσεις

| Αρχείο | Πότε το θέλεις |
|---|---|
| `csv/01-aksiotheata.csv` … `csv/10-metafores.csv` | **Το συνιστώ.** Ένα αρχείο ανά κατηγορία → κάθε ένα γίνεται ξεχωριστό **επίπεδο** με δικό του χρώμα και εικονίδιο, ακριβώς όπως έφτιαχνες τους χάρτες σου |
| `oslo-2026.kml` | Όλα μαζί σε ένα αρχείο, με φακέλους ανά κατηγορία |
| `oslo-ola-ta-meri.csv` | Όλα μαζί σε ένα επίπεδο |

**Κατέβασμα:** πάτα το αρχείο εδώ στο GitHub → κουμπί **Download raw file**.

Εναλλακτικά, μέσα από το site: **Ρυθμίσεις → Google My Maps → KML / CSV**. Αυτό βγάζει
πάντα την τελευταία έκδοση, ακόμα κι αν προσθέσουμε μέρη αργότερα.

## Βήματα

1. Πήγαινε στο <https://mymaps.google.com> → **Δημιουργία νέου χάρτη**
2. **Εισαγωγή** στο πρώτο επίπεδο → ανέβασε το `csv/01-aksiotheata.csv`
3. Στην ερώτηση **«Επιλέξτε στήλες για τοποθέτηση»** → τσέκαρε **Latitude** και **Longitude**
4. Στην ερώτηση **«Επιλέξτε στήλη τίτλου»** → διάλεξε **Όνομα**
5. **Προσθήκη επιπέδου** → επανέλαβε για κάθε επόμενο CSV
6. Σε κάθε επίπεδο πάτα **Στυλ** → διάλεξε χρώμα και εικονίδιο
7. Πάνω δεξιά **Κοινή χρήση** → *«Οποιοσδήποτε με τον σύνδεσμο»* → στείλε το link

> **Όριο:** το My Maps δέχεται **10 επίπεδα** ανά χάρτη. Οι κατηγορίες είναι ακριβώς 10,
> οπότε χωράνε όλες — αλλά δεν περισσεύει θέση για ενδέκατο.

## Τι περιέχει κάθε σημείο

Όνομα, συντεταγμένες, κατηγορία, κόστος, ωράριο, και περιγραφή που ενώνει
τι είναι το μέρος, την τιμή, το ωράριο και το «κόλπο» για κάθε σημείο.

Σημειώνονται επίσης τα **★ Διαμάντια** και όσα ήρθαν ως **πρόταση από τη συνάδελφο**.

## Προσοχή

Έξι σημεία έχουν **κατά προσέγγιση συντεταγμένες** και το γράφουν στην περιγραφή τους:
Paraplyen, Ekebergskrenten, Skøyenparken, Gråbein, SVANEN, Ugly Duckling. Μόλις μπουν
στο My Maps, μπορείς να σύρεις το pin στο σωστό σημείο με το χέρι.
