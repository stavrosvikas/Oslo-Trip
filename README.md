# Oslo 2026 🇳🇴

Διαδραστικός οδηγός ταξιδιού για το Όσλο — **25 Αυγούστου έως 2 Σεπτεμβρίου 2026**.
Static site, χωρίς build, χωρίς server, χωρίς λογαριασμούς. Ανοίγει και δουλεύει και offline.

---

## Τι κάνει

| Tab | Περιεχόμενο |
|---|---|
| **Μέρη** | Χάρτης και λίστα **στην ίδια οθόνη**. Κατηγορίες σε dropdown, τικ σε κάθε μέρος, κουμπί πλοήγησης που ανοίγει Google Maps. Η λίστα κυλάει, ο χάρτης και η κάτω μπάρα μένουν σταθερά. |
| **Πρόγραμμα** | 9 μέρες με ώρες, στάσεις, μεταφορικά και κόστος. Σύρε για αναδιάταξη ή στείλε στάση σε άλλη μέρα. |
| **Εκδρομές** | Εκδρομές εκτός Όσλο, με αναλυτικά βήματα και ειλικρινή κοστολόγηση. |
| **Οδηγός** | Μεταφορές, σούπερ μάρκετ, κανόνες αλκοόλ, ασφάλεια, καιρός, ενδυμασία, κρατήσεις. |

Οι ρυθμίσεις (θέμα, ποιος είσαι, ισοτιμία, offline χάρτης, εξαγωγή για My Maps, συγχρονισμός)
είναι πίσω από το εικονίδιο πάνω δεξιά — εκτός δρόμου, όχι σε tab.

**Μνήμη στη συσκευή** — τα τικ, τα αγαπημένα, οι σημειώσεις, οι αλλαγές στο πρόγραμμα και οι
δαπάνες αποθηκεύονται τοπικά (localStorage), **ξεχωριστά για κάθε άτομο**. Ο Σταύρος και η Ελένη
έχουν ανεξάρτητη πρόοδο ακόμα και στην ίδια συσκευή (Ρυθμίσεις → Ποιος είσαι).

> ### 🔒 Ιδιωτικότητα
> **Κανένα προσωπικό δεδομένο δεν υπάρχει σε αυτόν τον κώδικα.** Η ακριβής διεύθυνση διαμονής
> και ο κωδικός κράτησης της πτήσης δηλώνονται από τον καθένα στις **Ρυθμίσεις** και μένουν
> μόνο στη δική του συσκευή. Δεν ανεβαίνουν εδώ και **δεν περιλαμβάνονται ούτε στον κωδικό
> συγχρονισμού** που ανταλλάσσετε. Το pin του σπιτιού ξεκινά στο κέντρο της γειτονιάς
> (St. Hanshaugen) και το καρφιτσώνεις εσύ τοπικά.

**Συγχρονισμός** χωρίς server: Ρυθμίσεις → «Αντιγραφή» δίνει έναν κωδικό. Στέλνεις τον κωδικό,
ο άλλος τον κάνει «Εισαγωγή».

**Κάθε pin** έχει κουμπί «Οδηγίες» που ανοίγει το Google Maps στο κινητό με πλοήγηση με μέσα
από το σπίτι σας.

## Πώς το τρέχεις τοπικά

Διπλό κλικ στο `index.html`. Τέλος.

> Ο **service worker** (offline mode) απαιτεί `http://` και δεν ενεργοποιείται με `file://` —
> αυτό είναι φυσιολογικό και όλα τα υπόλοιπα δουλεύουν κανονικά. Θα ενεργοποιηθεί μόλις
> ανέβει σε GitHub Pages.

Αν θες κανονικό τοπικό server (για να δοκιμάσεις και το offline):

```bash
python -m http.server 8080
# ή
npx serve .
```

## Πώς ανεβαίνει στο GitHub Pages

Το repo είναι ήδη αρχικοποιημένο τοπικά με ένα commit. Δεν έχει remote — δεν έχει σταλεί τίποτα.

**1. Ενεργοποίησε το Pages:**
   Repo → **Settings** → **Pages** → Source: **Deploy from a branch** →
   Branch: `main`, φάκελος `/ (root)` → **Save**

**2. Σε ~1 λεπτό** θα είναι ζωντανό στο:
   `https://stavrosvikas.github.io/Oslo-Trip/`

**Για μελλοντικές αλλαγές:**

```bash
cd "e:/oslo travel/OSLO"
git add -A
git commit -m "τι άλλαξε"
git push
```

Αυτό το link στέλνεις στην Ελένη. Στο κινητό: **Μενού → Προσθήκη στην αρχική οθόνη** και
γίνεται εφαρμογή με δικό της εικονίδιο, που δουλεύει και χωρίς σήμα.

### Για να προσθέσεις ένα μέρος — από την εφαρμογή

Ο εύκολος τρόπος: **Χάρτης → κουμπί `+` → κλικ στο σημείο → όνομα, κατηγορία, τιμή, σημείωση.**
Αποθηκεύεται στη συσκευή σου, εμφανίζεται παντού (χάρτης, λίστες, αναζήτηση) και μπαίνει
και στην εξαγωγή για My Maps. Επεξεργασία ή διαγραφή από την καρτέλα του μέρους.

### Για να προσθέσεις ένα μέρος — μόνιμα στον κώδικα

Άνοιξε `assets/js/data.js`, βρες τον πίνακα `PLACES` και πρόσθεσε:

```js
{ id:'kati', name:'Νορβηγικό όνομα', nameEl:'Ελληνικό όνομα', cat:'food', gem:true,
  lat:59.9200, lng:10.7500, cost:180, costLabel:'~180 NOK',
  hours:'11:00–22:00',
  desc:'Τι είναι και γιατί αξίζει.',
  tip:'Το κόλπο που δεν ξέρει ο τουρίστας.' }
```

Κατηγορίες: `sight` `museum` `food` `bar` `cafe` `nature` `beach` `sauna` `shop` `transport`.
Μετά βάλ' το σε μια μέρα, στον πίνακα `ITINERARY`, με `{ t:'14:00', p:'kati', note:'…' }`.

## Σημειώσεις για τα δεδομένα

- Τιμές και ωράρια επαληθεύτηκαν τον **Αύγουστο 2026**. Το «~» σημαίνει κατά προσέγγιση.
- Το **Μουσείο Πλοίων Βίκινγκ είναι κλειστό ως το 2027** — οι Βίκινγκς είναι στο Historisk museum.
- Το φέρι **B2 προς Langøyene σταματά στις 30 Αυγούστου**, μέσα στο ταξίδι σας.
- **Δευτέρα κλείνουν**: Nasjonalmuseet, Astrup Fearnley, Historisk, Mathallen, Vippa.
- Οι **ζώνες προσοχής** στον χάρτη είναι «έχε τα μάτια σου ανοιχτά», όχι «μην πας».
  Το Όσλο είναι από τις ασφαλέστερες πρωτεύουσες της Ευρώπης.

## Τεχνικά

Vanilla JS, μηδέν framework, μηδέν build step. Μόνη εξωτερική εξάρτηση το **Leaflet 1.9.4**
+ **markercluster** από CDN (με SRI), και τα πλακίδια χάρτη από **CARTO/OpenStreetMap**.
Όλα τα εικονίδια είναι inline SVG sprite μέσα στο `index.html`.
